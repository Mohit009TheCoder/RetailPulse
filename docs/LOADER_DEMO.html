🎨 Customization

The loader can be easily customized by modifying CSS variables and animation durations.

Change Colors

:root { --primary: #6366f1; /* Change this */ }

Change Animation Speed

.loader-logo-icon { animation: spin 3s linear infinite; /* Slower */ }

Change Size

.loader-logo-icon { width: 80px; height: 80px; }
